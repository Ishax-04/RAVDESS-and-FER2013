# Machine Learning Assignment - RAVDESS & FER2013

This repository contains the code, analysis, and implementation for the machine learning assignment focusing on emotion and facial expression recognition using the **RAVDESS** and **FER2013** datasets.

## 📁 Repository Structure
* `MT26166_a1.ipynb`: The main Google Colab notebook containing data preprocessing, model building, training, and evaluation.

## 📊 Datasets Used
* **RAVDESS (Ryerson Audio-Visual Database of Emotional Speech and Song):** Used for audio/speech/facial emotion recognition tasks.
* **FER2013 (Facial Expression Recognition 2013):** Used for image-based facial emotion classification.
